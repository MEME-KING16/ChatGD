# Contributing to ChatGD

All contributions are welcome and appreciated! Whether you want to submit a bug report, give suggestions or help with development, all we ask is that you follow the guidelines below.

## Code of Conduct

Use common sense..

## Issues or bugs

Found a bug? You can submit an issue on this GitHub repository. Please do check if your specific problem already has an open issue. Also, **please only open issues that are related to CHATGD itself**, please make sure that it is chatgd.

## Submitting a Pull Request

Dont submit vibecoded pull requests they will be rejected

Make sure you have tested the feature or bugfix that you have implemented.
